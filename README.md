# 金融服务类企业绩效考核系统 — 操作手册

## 一、系统概述

本系统面向金融服务类企业，实现从绩效目标设定、考核执行、结果应用到多维度分析的完整绩效考核闭环。系统支持四种角色，各角色权限和操作流程如下。

---

## 二、角色说明

| 角色 | 代码 | 说明 |
|------|------|------|
| 系统管理员 | ADMIN | 系统配置、用户管理、全流程监管 |
| HR专员 | HR | 考核方案管理、KPI维护、薪酬调整审批 |
| 部门经理 | MANAGER | 上级评价、部门考核查看、部门报表 |
| 员工 | EMPLOYEE | 自评、互评、查看个人绩效、申诉 |

## 四、完整业务流程

### 流程总览

```
ADMIN/HR创建方案 → 配置评分规则 → 启动方案（自动生成任务+互评分配）
    ↓
员工自评（status 0→1）→ 上级评价（status 1→2）→ 互评（status 2→3）
    ↓
HR完成方案 → 生成薪酬调整建议 → 审批 → 员工查看/申诉
```

## 五、各角色操作流程

### 5.1 系统管理员（ADMIN）流程

#### 5.1.1 系统初始化

1. **登录系统**: 访问登录页，输入 `admin` / `123456`
2. **查看首页仪表盘**: 登录后自动跳转首页，可看到系统总览数据（员工总数、部门数、进行中方案数等）和图表

#### 5.1.2 用户管理

1. **侧边栏** → 系统管理 → 用户管理
2. **添加用户**: 点击"新增"按钮，填写用户名、密码、姓名、邮箱、手机号、部门、角色、状态
3. **编辑用户**: 点击操作列"编辑"按钮，可修改角色、部门、状态等
4. **重置密码**: 点击"重置密码"，用户密码将被重置为 `123456`
5. **禁用用户**: 编辑用户将状态改为"禁用"

#### 5.1.3 部门管理

1. **侧边栏** → 系统管理 → 部门管理
2. **添加部门**: 点击"新增"，填写部门名称、描述、排序号
3. **编辑部门**: 修改部门信息、指定部门经理

#### 5.1.4 公告管理

1. **侧边栏** → 系统管理 → 公告管理
2. **发布公告**: 点击"新增"，填写标题和内容，状态选"已发布"
3. **编辑/删除公告**: 在列表中操作

#### 5.1.5 操作日志

1. **侧边栏** → 系统管理 → 操作日志（仅ADMIN可见）
2. 查看所有用户的操作记录，包括登录、评分、审批等

#### 5.1.6 考核方案管理（与HR相同，见5.2）

---

### 5.2 HR专员流程

#### 5.2.1 KPI指标库维护

1. **侧边栏** → 绩效目标 → KPI指标库
2. **查看指标**: 系统已预置10个金融行业KPI指标
3. **新增指标**: 点击"新增"，填写指标名称、分类（财务类/合规类/风控类/客户类/运营类）、描述、公式、单位、目标值、最高分
4. **编辑/禁用指标**: 在列表中操作

#### 5.2.2 绩效目标管理

1. **侧边栏** → 绩效目标 → 目标管理
2. **创建公司级目标**: 点击"新增"，层级选"公司级"，填写标题、描述、年度
3. **创建部门级目标**: 层级选"部门级"，选择所属部门，关联上级目标
4. **创建个人级目标**: 层级选"个人级"，选择责任人，关联上级目标
5. **关联KPI**: 在目标详情中关联KPI指标，设置权重和目标值

#### 5.2.3 创建考核方案（核心流程）

1. **侧边栏** → 绩效考核 → 考核方案
2. **新增方案**: 点击"新增方案"，填写：
   - 方案名称：如 `2026年第二季度考核`
   - 年度：2026
   - 周期类型：季度
   - 周期编号：2
   - 考核日期：选择起止日期
   - 等级分数线：A级≥90、B级≥75、C级≥60（默认值）
   - 评分权重：自评20%、上级评60%、互评20%（默认值）
3. **配置评分规则**: 点击操作列"评分规则"按钮
   - 点击"添加"按钮，选择KPI指标，设置权重（如：合规完成率30%、风险控制得分30%、客户满意度20%、培训完成率20%）
   - 点击"保存规则"
4. **启动方案**: 点击操作列"启动"按钮
   - 系统自动为所有启用员工生成考核任务（状态=待自评）
   - 系统自动分配互评对象（同部门每人2人）
5. **查看互评分配**: 点击"互评分配"按钮，查看谁评价谁的分配详情
6. **查看进度**: 点击"进度"按钮，查看各阶段完成情况

#### 5.2.4 考核过程监控

1. **侧边栏** → 绩效考核 → 考核任务
2. 查看所有考核任务列表，可按方案、部门、状态筛选
3. 查看任务详情：点击"查看"，可看到评分明细和附件

#### 5.2.5 完成考核方案

1. 当所有任务状态变为"已完成"后，回到考核方案页面
2. 点击操作列"完成"按钮，系统自动计算最终得分和等级
3. 最终得分 = 自评总分×自评权重 + 上级评总分×上级评权重 + 互评总分×互评权重
4. 等级根据方案配置的分数线自动判定

#### 5.2.6 薪酬调整

1. **侧边栏** → 绩效结果 → 薪酬调整
2. **生成薪酬建议**: 点击"生成建议"按钮，选择已完成的方案
   - 系统根据等级自动生成调薪比例：A级15%、B级8%、C级3%、D级0%
3. **编辑薪酬**: 点击"编辑"，填写基本薪资、奖金金额
4. **审批**: 点击"审批"，通过或驳回

#### 5.2.7 多维度分析

1. **侧边栏** → 报表 → 多维度分析
2. 选择年度、周期、部门筛选条件，点击"查询"
3. 查看部门绩效趋势折线图、部门排名对比柱状图、绩效等级分布饼图

#### 5.2.8 报表导出

1. **侧边栏** → 报表 → 报表导出
2. 选择方案，导出考核结果报表

### 5.3 部门经理（MANAGER）流程

#### 5.3.1 查看首页

1. 登录后首页显示部门总览数据（部门人数、平均分、等级分布等）

2. 切换到"待我评分"标签页
3. 系统显示本部门中状态为"待上级评"的任务
4. 点击"评分"按钮：
   - 填写各KPI指标得分和评语
   - 点击"提交评分"
5. 提交后任务状态变为"待互评"

#### 5.3.4 查看部门考核情况

1. **侧边栏** → 绩效考核 → 部门考核
2. 在"全部任务"标签页查看本部门所有考核任务
3. 可按状态筛选查看进度

#### 5.3.5 部门薪酬查看

1. **侧边栏** → 绩效结果 → 部门薪酬
2. 查看本部门员工的薪酬调整记录

#### 5.3.6 部门发展计划

1. **侧边栏** → 绩效结果 → 部门发展计划
2. 查看和确认本部门员工的个人发展计划

#### 5.3.7 申诉处理

1. **侧边栏** → 绩效结果 → 部门申诉处理
2. 查看本部门员工的申诉，填写回复，通过或驳回

#### 5.3.8 多维度分析

1. **侧边栏** → 报表 → 多维度分析
2. 查看部门绩效趋势和排名对比

### 5.4 员工（EMPLOYEE）流程

#### 5.4.1 注册账号

1. 访问登录页，点击"注册账号"
2. 填写用户名、密码、确认密码、姓名、邮箱、手机号、**所属部门**（必选）
3. 注册成功后自动跳转登录页
4. 注册用户默认角色为"员工"

#### 5.4.2 查看首页

1. 登录后首页显示个人总览（待自评任务数、已完成考核数、最新绩效等级等）
2. 查看个人绩效趋势折线图和雷达图

#### 5.4.3 自评（核心操作）

1. **侧边栏** → 绩效考核 → 考核任务
2. 在"我的任务"标签页，找到状态为"待自评"的任务
3. 点击"评分"按钮：
   - 填写各KPI指标的自评得分和评语
   - 可上传附件作为自评证明材料
   - 点击"提交评分"
4. 提交后任务状态变为"待上级评"

#### 5.4.4 互评

1. **侧边栏** → 绩效考核 → 考核任务
2. 切换到"同事互评"标签页
3. 系统显示分配给当前用户的互评任务（同部门2位同事）
4. 点击"评分"按钮，填写各KPI指标评分和评语
5. 提交后该互评分配标记为"已完成"

#### 5.4.5 上传附件

1. 在任务详情弹窗中，切换到"附件"标签页
2. 点击"上传附件"，选择文件上传
3. 可下载已上传的附件

#### 5.4.6 查看绩效结果

1. 在"我的任务"标签页，查看已完成任务的最终得分和等级
2. 点击"查看"可看到自评、上级评、互评的详细评分

#### 5.4.7 个人发展计划

1. **侧边栏** → 绩效结果 → 发展计划
2. 查看基于考核结果自动生成的发展计划
3. 填写优势分析、待改进项、培训建议、发展目标、行动计划

#### 5.4.8 绩效申诉

1. **侧边栏** → 绩效结果 → 绩效申诉
2. 点击"新增申诉"，选择考核任务，填写申诉原因
3. 等待处理结果，可查看回复

#### 5.4.9 查看公告

1. **侧边栏** → 系统公告
2. 查看管理员/HR发布的公告

## 八、考核任务状态流转

```
┌─────────┐  员工自评   ┌──────────┐  上级评价   ┌─────────┐  互评完成   ┌─────────┐
│ 待自评   │ ────────→ │ 待上级评  │ ────────→  │ 待互评   │ ────────→ │ 已完成   │
│ status=0 │           │ status=1 │            │ status=2 │           │ status=3 │
└─────────┘           └──────────┘            └─────────┘           └─────────┘
```

**注意**：
- 互评不改变任务状态（status仍为2），需HR手动完成方案时统一计算
- 互评分配在提交评分后标记为"已完成"（peer_assignment.status=1）
- 方案完成时系统自动计算加权总分并判定等级

## 九、数据加密说明

系统对薪酬相关敏感字段（基本薪资、调薪比例、奖金金额）采用AES加密存储：
- 数据库中存储格式：`ENC:Base64密文`
- 读取时自动解密为BigDecimal数值
- 前端展示为正常数值，用户无感知
- 密钥配置在 `AesEncryptUtil.DEFAULT_KEY`

## 十、常见问题

### Q1: 启动方案时提示"请先为方案配置评分规则"
**A**: 需要先点击"评分规则"按钮，至少添加一条KPI规则后才能启动。

### Q2: 互评任务列表为空
**A**: 互评任务基于系统自动分配，只有在方案启动时才会生成。如果部门人数少于2人，则不会分配互评对象。

### Q3: 员工看不到考核任务
**A**: 确认HR已启动考核方案，且该员工状态为"启用"（status=1）且角色不是ADMIN。

### Q4: 经理看不到待评分任务
**A**: 确认员工已完成自评（任务状态=1待上级评），且经理与员工属于同一部门。

### Q5: 方案无法完成
**A**: 需要所有考核任务都达到"已完成"状态（status=3）后才能完成方案。

### Q6: 注册时选不到部门
**A**: 确认系统中已创建部门数据，部门状态为启用。
